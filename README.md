# SONATE-SDK

Public SDK monorepo for SONATE.

Packages:
- `@sonate/trust-receipts`
- `@sonate/core`
- `@sonate/schemas`
- `@sonate/verify-sdk`
- `sonate-receipt`

This repo intentionally excludes private product IP such as the trust kernel, policy packs, runtime evidence logic, and governance orchestration.
